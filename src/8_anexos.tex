\vspace{7pt}
\noindent\textbf{\normalsize CdU3 - Visualização de oportunidades}\\
\textbf{Agente:} Usuário \\ 
\textbf{Pré-Condições:} O usuário acessou o sistema.\\
\textbf{Pós-Condições:} O usuário visualiza as oportunidades ou os detalhes de uma oportunidade específica.\\
\textbf{Prioridade:} Alta \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O usuário acessa a página principal do sistema ou a opção “Oportunidades”.
    \item O sistema busca as oportunidades disponíveis.
    \item O sistema exibe as oportunidades retornadas junto da opção “Visualizar Oportunidade”, as opções de filtro para uma busca refinada e as opções de ordenação.
    \item O usuário clica na opção “Visualizar Oportunidade”.
    \item O sistema resgata os detalhes da oportunidade e as perguntas e respostas já realizadas.
    \item O sistema exibe mais informações sobre a oportunidade selecionada junto das perguntas e respostas.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Adição de filtros):}\\
No passo 3 do fluxo principal, se o usuário desejar a adição de filtros (data, município ou título) na busca:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O usuário insere os filtros desejados.
    \item O sistema realiza uma nova busca utilizando os filtros informados.
    \item O fluxo retorna ao passo 3 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 2 (Aplicação de ordenação):}\\
No passo 3 do fluxo principal, se o usuário desejar a aplicação de uma ordenação (orçamento ou data) dos resultados:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O usuário seleciona as formas de ordenação desejadas.
    \item O sistema exibe as oportunidades segundo a ordenação informada.
    \item O fluxo retorna ao passo 3 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Nenhum resultado encontrado):}\\
No passo 2 do fluxo principal ou do fluxo alternativo 1, se a busca não retornar resultados:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao usuário que não existem oportunidades cadastradas no sistema que atendam aos critérios ou filtros inseridos.
\end{enumerate}

\noindent\textbf{\normalsize CdU4 - Cadastro de Propostas}\\
\noindent\textbf{Agente:} Prestador de Serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema, existe uma oportunidade no sistema, a oportunidade permite o cadastro de propostas (RN11) e o MEI ainda não cadastrou uma proposta para aquela oportunidade (RN10).\\ 
\textbf{Pós-Condições:} O MEI possuirá uma proposta cadastrada ou um rascunho salvo para aquela oportunidade.\\
\textbf{Prioridade:} Alta \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:} 
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI está visualizando os detalhes de uma oportunidade e seleciona a opção “Fazer Proposta”. 
    \item O sistema verifica se existe um rascunho para aquela oportunidade. Caso sim, resgata o rascunho; caso não, inicia um novo cadastro. 
    \item O sistema recupera as informações de perfil do MEI. 
    \item O sistema exibe as informações de perfil do MEI junto do formulário contendo os campos a serem preenchidos de acordo com o DD02. No caso do usuário já possuir um rascunho, o sistema também exibe o conteúdo que havia sido preenchido. 
    \item O MEI preenche os campos do formulário. 
    \item O MEI insere os arquivos solicitados. 
    \item O sistema valida imediatamente o formato e o tamanho do arquivo (DD02). 
    \item O MEI confirma o envio da proposta.
    \item O sistema realiza a validação das informações inseridas. 
    \item O sistema guarda as informações da proposta com o status ``em análise". 
    \item O sistema informa ao MEI que a proposta foi realizada. 
    \item O sistema retorna para a parte de detalhes da oportunidade. 
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Salvar Rascunho):}\\ 
Até o passo 7 do fluxo principal, se o MEI salvar o cadastro como rascunho: 
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema guarda as informações inseridas como rascunho. 
    \item O sistema informa ao usuário que os dados foram salvos.
    \item O sistema retorna para a tela de detalhes da oportunidade. 
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Arquivo fora dos padrões):}\\ 
No passo 7 do fluxo principal, se o MEI insere um documento fora dos padrões (DD02): 
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema mostra que o documento não pode ser enviado. 
    \item O sistema mostra os tipos permitidos de documentos e os tamanhos máximos.
    \item O sistema retorna para a tela de cadastro de proposta com os dados já preenchidos.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 2 (Erro no envio de arquivo):}\\ 
No passo 7 do fluxo principal, se o documento enviado pelo MEI tiver um erro de envio:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema exibe uma opção de realizar o envio do documento novamente. 
    \item O fluxo retorna ao passo 6 do fluxo principal. 
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 3 (Campos em branco):}\\ 
No passo 9 do fluxo principal, se o MEI não preencheu algum dos campos obrigatórios: 
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao MEI que é necessário o preenchimento de todos os campos obrigatórios. 
    \item O sistema retorna para a tela de cadastro com os dados já preenchidos. 
    \item O sistema destaca o campo não preenchido. 
\end{enumerate}

\noindent\textbf{\normalsize CdU5 - Visualização de ``minhas propostas''}\\
\noindent\textbf{Agente:} Prestador de serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema.\\ 
\textbf{Pós-Condições:} O MEI visualiza as suas propostas, os detalhes de uma proposta ou os detalhes de uma oportunidade.\\
\textbf{Prioridade:} Média \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI acessa a página de ``minhas propostas''.
    \item O sistema busca as propostas já feitas pelo MEI.
    \item O sistema exibe as propostas retornadas e seus respectivos status junto das opções ``Visualizar Proposta'', ``Visualizar Oportunidade'' e opções de filtro para uma busca refinada.
    \item O usuário clica na opção ``Visualizar Proposta''.
    \item O sistema exibe mais informações sobre a proposta selecionada junto dos botões de edição e de exclusão da proposta (RN25).
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Adição de filtros):}\\
No passo 3 do fluxo principal, se o usuário desejar a adição de filtros na busca:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O usuário insere os filtros desejados.
    \item O sistema realiza uma nova busca utilizando os filtros informados.
    \item O fluxo retorna ao passo 3 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 2 (Visualizar Oportunidade):}\\
No passo 4 do fluxo principal, se o usuário acessar a opção ``Visualizar Oportunidade'':
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema recupera as informações da oportunidade relacionada àquela proposta.
    \item O sistema exibe as informações da oportunidade (como no passo 5 do fluxo principal do CdU3).
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Nenhum resultado encontrado):}\\
No passo 2 do fluxo principal ou do fluxo alternativo 1, se a busca não retornar resultados:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao MEI que não existem propostas cadastradas que atendam aos critérios de busca.
\end{enumerate}

\noindent\textbf{\normalsize CdU6 - Visualização de ``meus rascunhos''}\\
\noindent\textbf{Agente:} Prestador de serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema.\\ 
\textbf{Pós-Condições:} O MEI visualiza os seus rascunhos ou o formulário de cadastro de proposta.\\
\textbf{Prioridade:} Média \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI acessa a página de ``meus rascunhos''.
    \item O sistema busca os rascunhos já salvos pelo MEI.
    \item O sistema exibe os rascunhos retornados junto da opção ``Continuar Cadastro'' para cada um e opções de filtro para uma busca refinada.
    \item O usuário clica na opção ``Continuar Cadastro''.
    \item O sistema valida se ainda é possível submeter propostas para aquela oportunidade.
    \item O sistema resgata as informações do rascunho.
    \item O sistema direciona o usuário para a tela de cadastro de propostas com as informações resgatadas (conforme o CdU4).
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Adição de filtros):}\\
No passo 3 do fluxo principal, se o usuário desejar a adição de filtros na busca:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O usuário insere os filtros desejados.
    \item O sistema realiza uma nova busca utilizando os filtros informados.
    \item O fluxo retorna ao passo 3 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Nenhum resultado encontrado):}\\
No passo 2 do fluxo principal ou do fluxo alternativo 1, se a busca não retornar resultados:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao MEI que não existem rascunhos salvos que atendam aos critérios de busca.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 2 (Prazo de submissão encerrado):}\\
No passo 5 do fluxo principal, se o prazo para submissão de propostas da oportunidade tiver acabado (RN11):
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao usuário que a oportunidade não permite mais o envio de propostas.
    \item O sistema resgata as informações do rascunho.
    \item O sistema exibe o formulário de cadastro com as informações resgatadas, mas sem permitir que o usuário o edite ou envie a proposta.
\end{enumerate}

\noindent\textbf{\normalsize CdU7 - Perguntas sobre oportunidades}\\
\noindent\textbf{Agente:} Prestador de serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema, existe uma oportunidade aberta no sistema e o MEI não possui três perguntas em análise naquela oportunidade (RN16).\\ 
\textbf{Pós-Condições:} O prestador de serviços terá uma pergunta realizada.\\
\textbf{Prioridade:} Baixa \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI seleciona a opção ``Visualizar Oportunidade''.
    \item O sistema resgata os detalhes da oportunidade e as perguntas e respostas já realizadas.
    \item O sistema exibe os detalhes da oportunidade, as perguntas e respostas já realizadas e uma opção de realizar uma nova pergunta.
    \item O MEI seleciona a opção de realizar uma nova pergunta.
    \item O sistema exibe um campo para o usuário escrever sua pergunta.
    \item O MEI preenche o campo com sua pergunta e a envia.
    \item O sistema guarda a pergunta realizada com o status ``em análise''.
    \item O sistema confirma o envio da pergunta.
    \item O sistema retorna para a tela de visualização da oportunidade.
\end{enumerate}

\noindent\textbf{\normalsize CdU10 - Cadastro de Oportunidade}\\
\noindent\textbf{Agente:} Agente Público\\ 
\textbf{Pré-Condições:} O agente está logado no sistema.\\ 
\textbf{Pós-Condições:} O agente terá uma oportunidade cadastrada ou um rascunho salvo no sistema.\\
\textbf{Prioridade:} Alta \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O agente seleciona a opção de cadastrar uma oportunidade.
    \item O sistema exibe o formulário de cadastro de oportunidade (DD03).
    \item O agente preenche as informações do formulário.
    \item O agente insere as mídias desejadas.
    \item O sistema imediatamente valida o tamanho e o formato dos arquivos inseridos.
    \item O agente envia o formulário.
    \item O sistema valida as informações inseridas.
    \item O sistema salva as informações do cadastro e adiciona o status como pendente (caso funcionário) ou como aprovado (caso manager).
    \item O sistema confirma o cadastro para o agente.
    \item O sistema retorna para a tela em que o agente estava antes de cadastrar a oportunidade.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Salvar Rascunho):}\\

\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema guarda as informações inseridas como rascunho.
    \item O sistema informa ao agente que os dados foram salvos.
    \item O sistema retorna para a tela que o agente estava antes de iniciar o cadastro de uma nova oportunidade.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Arquivo fora dos padrões):}\\

    \item O sistema mostra os tipos permitidos de documentos e os tamanhos máximos.
    \item O sistema retorna para a tela de cadastro de oportunidade com os dados já preenchidos.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 2 (Erro de envio de arquivo):}\\
No passo 5 do fluxo principal, se o documento enviado pelo agente tiver um erro de envio:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema exibe uma opção para realizar o envio do documento novamente.
    \item O fluxo retorna ao passo 4 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 3 (Um ou mais campos obrigatórios em branco):}\\
No passo 7 do fluxo principal, se o sistema validar que algum dos campos obrigatórios não foi preenchido:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao agente que é necessário o preenchimento de todos os campos obrigatórios.
    \item O sistema retorna para a tela de cadastro com os dados que o agente preencheu.
    \item O sistema destaca em vermelho o campo que não foi preenchido.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 4 (RN14 - Exclusivo para manager):}\\
No passo 7 do fluxo principal, se o sistema validar que o manager inseriu um prazo para realização da proposta inferior ao prazo de recebimento de propostas (RN14):
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao manager que ele precisa inserir um prazo para realização da proposta maior ou um prazo para recebimento de propostas menor.
    \item O sistema retorna para o formulário de cadastro.
    \item O sistema destaca os campos que precisam ser alterados.

\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]

\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI acessa a opção de edição de propostas.
    \item O sistema carrega a proposta do MEI e a exibe.
    \item O MEI altera os campos desejados.
    \item O MEI insere novos arquivos.
    \item O sistema valida imediatamente o tamanho e o formato dos arquivos.
    \item O MEI confirma a alteração da proposta.
    \item O sistema valida os campos alterados.
    \item O sistema guarda as novas informações.
    \item O sistema confirma a edição da proposta.
    \item O sistema retorna para a tela em que o MEI estava antes de editar a proposta.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Cancelamento da edição):}\\
Até o passo 6 do fluxo principal, se o MEI cancelar a edição da proposta:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema confirma o cancelamento da edição.
    \item O sistema retorna para a tela em que o MEI estava antes de editar a proposta.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 1 (Arquivo fora dos padrões):}\\
No passo 5 do fluxo principal, se o sistema validar que o MEI inseriu um documento fora dos padrões (DD02):
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema mostra que o documento não pode ser enviado.
    \item O sistema mostra os tipos permitidos de documentos e os tamanhos máximos.
    \item O sistema retorna para a tela de edição de proposta com os dados já preenchidos.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 2 (Erro de envio de arquivo):}\\
No passo 4 do fluxo principal, se o documento enviado pelo MEI apresentar um erro de envio:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema exibe uma opção para realizar o envio do documento novamente.
    \item O fluxo retorna ao passo 4 do fluxo principal.
\end{enumerate}

\noindent\textbf{Fluxo de Exceção 3 (Um ou mais campos obrigatórios em branco):}\\
No passo 7 do fluxo principal, se o sistema validar que o MEI deixou algum dos campos obrigatórios em branco:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema informa ao MEI que é necessário o preenchimento de todos os campos obrigatórios.
    \item O sistema retorna para a tela de edição com os dados já preenchidos.
    \item O sistema destaca em vermelho o campo não preenchido.
\end{enumerate}

\vspace{7pt}
\noindent\textbf{\normalsize CdU18 - Remoção de Proposta}\\
\noindent\textbf{Agente:} Prestador de serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema, possui uma proposta cadastrada e o prazo de submissão de propostas ainda não foi encerrado (RN25).\\ 
\textbf{Pós-Condições:} O MEI terá removido a sua proposta.\\
\textbf{Prioridade:} Baixa \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI seleciona a opção de remover a sua proposta.
    \item O sistema exibe uma solicitação de confirmação, informando as consequências de apagar a proposta.
    \item O MEI confirma a remoção da proposta.
    \item O sistema realiza a remoção da proposta no banco de dados.
    \item O sistema confirma para o MEI que a proposta foi removida.
    \item O sistema retorna para a tela em que o MEI estava antes de remover a proposta.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Cancelamento da remoção):}\\
No passo 3 do fluxo principal, se o MEI cancelar a remoção da proposta:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema confirma o cancelamento da remoção da proposta.
    \item O sistema retorna para a tela em que o MEI estava antes de selecionar a opção de remover a proposta.
\end{enumerate}

\vspace{7pt}
\noindent\textbf{\normalsize CdU19 - Aceitar/Rejeitar Serviço}\\
\noindent\textbf{Agente:} Prestador de serviços (MEI)\\ 
\textbf{Pré-Condições:} O MEI está logado no sistema e possui uma proposta selecionada e aprovada.\\ 
\textbf{Pós-Condições:} O MEI terá aceitado ou rejeitado a realização do serviço.\\
\textbf{Prioridade:} Alta \vspace{3pt}\\
\noindent\textbf{Fluxo Principal:}
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O MEI acessa a proposta aprovada e visualiza as opções ``Aceitar Serviço'' e ``Rejeitar Serviço''.
    \item O MEI seleciona a opção de ``Aceitar Serviço''.
    \item O sistema solicita a confirmação de que o MEI deseja aceitar o serviço.
    \item O MEI confirma que deseja aceitar o serviço.
    \item O sistema atualiza o status da proposta para aceita.
    \item O sistema confirma para o MEI que o serviço foi aceito.
    \item O sistema retorna para a tela de detalhes da proposta.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 1 (Rejeitar Serviço):}\\
No passo 2 do fluxo principal, se o MEI selecionar a opção ``Rejeitar Serviço'':
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema solicita a confirmação de que o MEI deseja rejeitar o serviço.
    \item O MEI confirma que deseja rejeitar o serviço.
    \item O sistema atualiza o status da proposta para rejeitada.
    \item O sistema confirma para o MEI que o serviço foi rejeitado.
    \item O sistema retorna para a tela de detalhes da proposta.
\end{enumerate}

\noindent\textbf{Fluxo Alternativo 2 (Cancelamento da ação):}\\
Durante o passo 3 do fluxo principal ou o passo 1 do fluxo alternativo 1, se o MEI cancelar a ação:
\begin{enumerate}[noitemsep, topsep=-5pt, parsep=0pt]
    \item O sistema confirma que a ação foi cancelada.
    \item O sistema retorna para a tela de detalhes da proposta.
\end{enumerate}

\vspace{10pt}
\noindent{\large\textbf{Regras de Negócio}}
\vspace{10pt}

\begin{description}[noitemsep, topsep=0pt, parsep=0.6pt, leftmargin=1.8cm, labelwidth=1.5cm]
    %\item[\label{rn:01}RN01 -] \textbf{Validação de CPF/CNPJ:} O sistema deve validar os dígitos verificadores do CPF e do CNPJ conforme as normas da Receita Federal.
    
    %\item[\label{rn:02}RN02 -] \textbf{Unicidade de CPF/CNPJ e e-mail:} O sistema deve garantir que cada CPF, CNPJ e e-mail cadastrado seja único no sistema. 
    
    %\item[\label{rn:03}RN03 -] \textbf{Validação de CEP:} O sistema deve validar o CEP inserido para garantir que este corresponda a um endereço existente. 
    
    %\item[\label{rn:04}RN04 -] \textbf{Formato de Telefone:} O sistema deve validar se o telefone segue o padrão nacional. 
    
    %\item[\label{rn:05}RN05 -] \textbf{Login:} O login do sistema deve ser feito mediante ``CPF'' e ``senha'' ou através do login do Gov.br. 
    
    %\item[\label{rn:06}RN06 -] \textbf{Formato do E-mail:} O sistema deve validar se o texto inserido respeita a sintaxe padrão de endereços de e-mail. 
    
    %\item[\label{rn:07}RN07 -] \textbf{Segurança das Senhas:} O sistema deve garantir que as senhas apresentadas pelo usuário correspondam a um padrão mínimo de segurança, como possuir pelo menos 8 caracteres. 
    
    %\item[\label{rn:08}RN08 -] \textbf{Confirmação de Senha:} O sistema deve exigir uma confirmação sempre que o usuário desejar criar uma nova senha, garantindo que a senha informada e a sua confirmação possuam exatamente o mesmo valor. 
    
    \item[\label{rn:09}RN09 -] \textbf{Cadastro de Oportunidades:} O sistema deve garantir que apenas agentes públicos cadastrem oportunidades no sistema e que um agente público só possa cadastrar oportunidades referentes ao seu respectivo órgão. 
    
    \item[\label{rn:10}RN10 -] \textbf{Cadastro de Propostas:} O sistema deve garantir que apenas prestadores de serviço cadastrem propostas nas oportunidades existentes e que cada prestador consiga cadastrar apenas uma proposta para uma determinada oportunidade. 
    
    \item[\label{rn:11}RN11 -] \textbf{Prazo para Cadastro de Propostas:} O sistema deve garantir que as propostas sejam cadastradas apenas durante o prazo determinado no cadastro da oportunidade. 
    
    \item[\label{rn:12}RN12 -] \textbf{Rascunhos de Propostas:} O sistema deve garantir que um prestador de serviços (MEI) não possua mais de um rascunho para uma mesma oportunidade. 
    
    \item[\label{rn:13}RN13 -] \textbf{Cadastro de Agentes Públicos:} O sistema deve garantir que apenas um manager possa cadastrar outro agente público. 
    
    \item[\label{rn:14}RN14 -] \textbf{Consistência de Datas:} O sistema deve garantir que a data de início da execução do serviço seja posterior à data limite estabelecida para o recebimento de propostas. 
    
    \item[\label{rn:15}RN15 -] \textbf{Realização de Perguntas:} O sistema deve garantir que apenas prestadores de serviço sejam capazes de realizar perguntas nas oportunidades. 

    \item[\label{rn:16}RN16 -] \textbf{Limite de Perguntas ``Em Análise'':} O prestador de serviços pode possuir no máximo três perguntas com status ``Em Análise'' para uma mesma oportunidade. 

    \item[\label{rn:17}RN17 -] \textbf{Resposta de Perguntas:} O sistema deve garantir que apenas agentes públicos sejam capazes de responder a uma pergunta e que haja apenas uma resposta por pergunta. 

    \item[\label{rn:18}RN18 -] \textbf{Tréplica de Perguntas:} O sistema deve garantir que não seja possível para o prestador de serviços responder à resposta de uma pergunta. 

    \item[\label{rn:19}RN19 -] \textbf{Publicidade de Perguntas:} O sistema deve garantir que uma pergunta só se torne pública a partir do momento em que um agente público a responder e que em nenhum momento seja possível identificar o autor da pergunta. 

    \item[\label{rn:20}RN20 -] \textbf{Aprovação de Oportunidades:} Oportunidades criadas por agentes públicos requerem aprovação explícita de um perfil Manager para serem publicadas. Oportunidades criadas por Managers são publicadas automaticamente. 

    \item[\label{rn:21}RN21 -] \textbf{Seleção de Proposta:} Quando o período de cadastro de propostas se encerrar, o sistema irá selecionar a proposta mais vantajosa de acordo com o critério definido na criação da oportunidade. Em caso de empate, a proposta enviada primeiro será a selecionada. 

    \item[\label{rn:22}RN22 -] \textbf{Visibilidade de Informações das Propostas:} As informações relacionadas a uma proposta só serão visíveis para os agentes públicos em duas situações: (1) a proposta foi selecionada como a mais vantajosa e a oportunidade está no período de julgamento; ou (2) a proposta não foi selecionada como a mais vantajosa, mas a oportunidade já foi finalizada. 

    \item[\label{rn:23}RN23 -] \textbf{Período para Atualização da Documentação:} Durante o período de julgamento, caso sejam constatadas pendências documentais relacionadas aos arquivos enviados pelo prestador de serviços no ato de realização das propostas, este possuirá 5 dias úteis para atualizar a documentação. Será aceito apenas o envio de novas versões dos documentos já submetidos. Para os demais documentos, o prazo de atualização é de 2 dias úteis. 

    \item[\label{rn:24}RN24 -] \textbf{Publicidade das Propostas:} Todas as propostas feitas em uma oportunidade serão visíveis para todos os usuários apenas após a oportunidade ser finalizada. 

    \item[\label{rn:25}RN25 -] \textbf{Edição/Exclusão das Propostas:} Durante o período de submissão de propostas de uma oportunidade, o MEI pode editar ou remover a sua proposta. 

    \item[\label{rn:26}RN26 -] \textbf{Oportunidade sem Propostas:} Caso uma oportunidade não tenha recebido nenhuma proposta durante o período de submissão, ela será finalizada quando o prazo se encerrar. O mesmo ocorrerá caso, após a rejeição de uma proposta no período de julgamento, não houver outras propostas aptas para seleção. 
\end{description}
